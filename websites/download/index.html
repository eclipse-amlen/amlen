Pre-Releases and Betas

1.1.0

1.1.0-rc1 is now available. A release-candidate version containing an ansible based operator and supporting more recent operating systems. It is available for RHEL/AlmaLinux 8, 9 and 10 and Fedora 42.

Download 1.1rc1

NB: The WebUI requires openldap-servers which for RHEL 10 is available in EPEL and for older releases is available in the RHEL CodeReady Builder stream for RHEL(PowerTools for CentOS/AlmaLinux).
Alternatively openldap-servers is available from the symas repo.

Current Stable Releases

1.0.0.2

1.0.0.2 is now available. A minor update to 1.0.0.0/1.0.0.1 with the main differences being fixes to the WebUI and the Kafka Bridge.

  • CentOS7/RHEL7 downloads: Amlen Server 1.0.0.2, Amlen WebUI 1.0.0.2, Amlen Bridge 1.0.0.2, Others
  • RHEL8/AlmaLinux8: Amlen Server 1.0.0.2, Amlen WebUI 1.0.0.2, Amlen Bridge 1.0.0.2, Others
    NB: The WebUI requires openldap-servers which is available in the RHEL CodeReady Builder stream for RHEL(PowerTools for CentOS/AlmaLinux).
    Alternatively openldap-servers is available from the symas repo.
