1.1

1.1 is now available. Includes support for RHEL up to RHEL 10.

NB: The WebUI requires openldap-servers which for RHEL 10 is available in EPEL and for older releases is available in the RHEL CodeReady Builder stream for RHEL(PowerTools for CentOS/AlmaLinux).
Alternatively openldap-servers is available from the symas repo.

  • RHEL8/Almalinux8 downloads: Amlen Server 1.1, Amlen WebUI 1.1, Others
  • RHEL9/Almalinux9 downloads: Amlen Server 1.1, Amlen WebUI 1.1, Others
  • RHEL10/Almalinux10 downloads: Amlen Server 1.1, Amlen WebUI 1.1, Others
